# Images du site

Déposez vos photos ici avec **exactement** ces noms de fichier : elles s'afficheront
automatiquement à la place du visuel dégradé temporaire (aucune modification de code).

| Fichier            | Emplacement            | Taille conseillée | Sujet                                  |
| ------------------ | ---------------------- | ----------------- | -------------------------------------- |
| `hero.jpg`         | Accueil (grande image) | ~1200 × 1000 px   | Ambiance du studio, équipe au travail  |
| `photo.jpg`        | Carte « Photo »        | ~800 × 500 px     | Studio photo, fond blanc, éclairage    |
| `video.jpg`        | Carte « Vidéo »        | ~800 × 500 px     | Caméra, fond vert, tournage            |
| `podcast.jpg`      | Carte « Podcast »      | ~800 × 500 px     | Cabine son, micros, casques            |

Conseils :
- Formats acceptés : `.jpg`, `.png`, `.webp` — mais gardez le **nom indiqué** (ex. `hero.jpg`).
- Privilégiez des images **horizontales nettes** et légères (< 500 Ko) pour la vitesse.
- Tant qu'un fichier est absent, un dégradé violet/ambre avec une icône s'affiche à la place.
